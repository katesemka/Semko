# Лабораторная № 1. Поиск по каталогу землетрясений

Вариант: `earthquakes-jsonl | all | raw | fuzzy-words | top10 | plain | stars`.

Это учебный каркас. В функциях есть сигнатуры, описание результата и комментарии
с шагами реализации. `raise NotImplementedError` отмечает место для твоего кода:
замени эту строку реализацией функции. Сейчас программа ещё не выполняет поиск.

## Файлы

| Файл | Назначение |
| --- | --- |
| `main.py` | Запуск, цикл ввода, обработка ошибок |
| `commands.py` | Разбор команд, проверка аргументов, вызов нужных функций |
| `config.py` | Вариант, схема полей, операторы, начальный порог, лимит |
| `models.py` | Классы для хранения данных между вызовами функций |
| `storage.py` | Построчная загрузка JSONL и сохранение текста |
| `filters.py` | Создание фильтров и проверка записей |
| `search.py` | Сравнение слов, релевантность и выбор десяти результатов |
| `output.py` | Подготовка карточек и справочной информации |
| `earthquakes.jsonl` | Место для исходного каталога; файл пока пустой |

## Что делает каждый класс

- `Earthquake` — карточка одного землетрясения с полями из JSONL.
- `Filter` — одно условие: имя поля, оператор и значение нужного типа.
- `SearchResult` — найденная карточка вместе с релевантностью и оценкой.
- `AppState` — общее состояние: каталог, настройки, оценки и последняя выдача.

Это классы с `@dataclass`: Python сам создаёт конструкторы по перечисленным полям.
Своих методов у них нет. Загрузка, поиск и форматирование находятся в функциях.
Так классы работают как подписанные коробки для данных.

## Как связаны модули

`main` создаёт `AppState` и передаёт строку в `commands`.
Обработчик вызывает `storage`, `filters`, `search` или `output` по назначению команды.
`search` использует `filters`, чтобы отобрать записи до сравнения слов.
`output` возвращает текст, который обработчик печатает и при необходимости запоминает.
`models` задаёт общий формат данных, `config` — общие настройки.

## Поиск для этого варианта

`all`: поисковые поля перечислены в `config.SEARCH_FIELDS`.
В этом каркасе в них входят все строковые поля схемы: `id`, `title`, `kind`,
`network`, `time`, `url`. Числовые поля и `reviewed` используются в фильтрах.

`raw`: запрос и поля делятся на слова по пробельным символам.
Регистр и пунктуация сохраняются, поэтому `Texas` и `texas` отличаются.

Для сравнения слов выбрано расстояние Левенштейна — минимальное число вставок,
удалений и замен символов. Сходство непустых слов:

```text
similarity(a, b) = 1 - distance(a, b) / max(len(a), len(b))
```

Для двух пустых строк сходство равно 1, для пустой и непустой — 0.
Для каждого слова запроса ищется наибольшее сходство со словами записи.
Запись подходит, если каждое из этих сходств не меньше `threshold`.
Начальный порог — 0.8; его можно поменять командой.

```text
relevance = сумма лучших сходств / число слов запроса
```

Фильтры применяются одновременно до поиска и ограничения выдачи.
Среди подходящих записей сортировка идёт по убыванию релевантности.
При равной релевантности сохраняется исходный порядок.
Показываются первые десять результатов, число найденных считается до ограничения.
Время поиска измеряется через `time.perf_counter()` без печати карточек.

Пустой запрос применяет только фильтры, релевантность равна нулю.
Подсветки нет. Оценки от 1 до 5 показываются отдельно и не меняют порядок выдачи.

## Что важно сохранить при реализации

- До загрузки доступны только `help`, `load`, `exit`.
- Аргументы разбираются через `shlex.split()`, включая пути и значения в кавычках.
- Ошибка команды объясняется пользователю и не завершает цикл ввода.
- `show` показывает все записи и поля независимо от фильтров и лимита.
- `None` и пустая строка не проходят фильтр, в том числе `ne`; ноль и `False` допустимы.
- Фильтры и порог применяются при следующем `search`.
- Успешные `show` и `search` запоминают показанный текст и ID записей.
- `save` сохраняет этот текст; `rate` разрешён только для ID последней показанной выдачи.
- Оценки сохраняются между запросами, новая оценка заменяет старую.
- Успешный `load` сбрасывает фильтры, порог, оценки и последнюю выдачу.
- Ошибка загрузки оставляет прежнее состояние.

## Порядок заполнения каркаса

1. `storage`: чтение JSONL и создание `Earthquake`.
2. `output`: карточки, затем `commands`: загрузка, `show`, справка и цикл в `main`.
3. `filters`: типы значений и одновременная проверка условий.
4. `search`: расстояние между словами, сходство, проверка записи, общий поиск.
5. Оставшиеся обработчики команд, оценки, сохранение и сообщения об ошибках.
6. Проверка поведения на небольшом каталоге и дополнение этого отчёта результатами.
